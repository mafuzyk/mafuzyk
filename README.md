# mafu

I build things to find out how they work. Often a terminal tool in Rust, sometimes a game in Godot, usually because some existing tool annoyed me first.

I'm 17, self-taught, and in my third year of a technical high school in Environmental Management, which has nothing to do with any of this. I write most of it from Brazil, between classes.

## what I'm building

### [Kernel Panic](https://github.com/mafuzyk/kernel-panic) — a neon arena shooter
Started on an Android phone with Godot and Termux: no PC, no keyboard, no excuse. 4.0 is out.

`Godot 4` · `GDScript` · `desktop` · `v4.0.0`

### [Escargot Native](https://github.com/mafuzyk/escargot-native) — MSN Messenger 7.5, on Linux
An unofficial native client for the Escargot network, rebuilt to feel identical to the Windows app instead of running it through Wine.

`Rust` · `GPUI` · `wgpu` · `Linux` · `in progress`

### also building

- **[sharky](https://github.com/mafuzyk/sharky-shell)** — an interactive shell in Ruby with its own lexer, parser, executor and job control. No third-party gems.
  `Ruby` · `Linux` · `v1.0.1`
- **[halofetch](https://github.com/mafuzyk/halofetch)** — a system fetch tool with centered ASCII art and powerline panels. GPL-3.0 keeps the code free: use it, change it, ship it, just don't close it.
  `Rust` · `Linux` · `v3.0.0`

The rest stays private for now: a Discord client in C++/Qt and a harness that drives coding agents. They go public when they stop embarrassing me.

## stack

Rust, C++, TypeScript, GDScript, Ruby, QML, Lua, plus Python and Shell when the problem is small.

## on agents

I use coding agents openly, and I say so. Most of what is here was built with them in the loop: I set the direction, review the diffs and debug what breaks, they do the typing. Pretending otherwise would be dishonest about how this code got written, and about how software gets written now.

## how I work

Ugly version first, then delete half of it. I would rather ship something that runs on the machine in front of me than design for a use case I don't have.

Error reports are the most useful thing anyone can send me, especially from hardware I don't own.
