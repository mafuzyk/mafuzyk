# mafu

I build things to find out how they work. Often a terminal tool in Rust, sometimes a game in Godot, usually because some existing tool annoyed me first.

Self-taught. I write most of this from Brazil, between school and a technical course that has nothing to do with any of it.

## what I'm building

**[Kernel Panic](https://github.com/mafuzyk/kernel-panic)** — a neon arena shooter. I started it on an Android phone with Godot and Termux: no PC, no keyboard. 4.0 is out.

**[halofetch](https://github.com/mafuzyk/halofetch)** — a system fetch tool with centered ASCII art and powerline panels, pure Rust. GPL-3.0, because I want people to actually use it.

**[zzz-rice](https://github.com/mafuzyk/zzz-rice)** — Hyprland rice with a ZZZ live wallpaper. Personal config, kept public because ricing is a sport.

The rest stays private for now: a Discord client in C++/Qt, a Rust shell, a harness that drives coding agents. They go public when they stop embarrassing me.

## stack

Rust, C++, TypeScript, GDScript, QML, Lua, plus Python and Shell when the problem is small.

## how I work

Ugly version first, then delete half of it. I would rather ship something that runs on the machine in front of me than design for a use case I don't have.

Error reports are the most useful thing anyone can send me, especially from hardware I don't own.
